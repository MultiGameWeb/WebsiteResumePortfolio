# Admin controls — Photography Template 01 v3

## Quick customer setup

The customer only needs to provide:

- Business name
- Owner / photographer name
- WhatsApp number
- Call number
- Email
- Location name
- Google Maps link
- About Us text (optional)
- Home heading / text (optional)
- Hero image chosen from admin storage

Everything else can use the default content until the owner wants to edit it.

## Full admin control

- Business identity: business name, owner name, motto, experience, specialties
- Home: ribbon, hero badge, heading, subtitle, CTA labels, proof points, middle CTA
- Site Copy: section headings, captions, footer labels and customer-facing text
- Images & Storage: upload, browser-side compression, choose, use as hero, delete
- Video: add/edit/delete YouTube/Vimeo links and show/hide
- Services: add/edit/delete and show/hide
- Gallery: add/edit/delete, choose stored image, category, featured video, show/hide
- Reviews: add/edit/delete, rating, source, show/hide
- Contact & Links: WhatsApp, Call number, Email, Location, Google Maps, Instagram, Facebook, YouTube, Pinterest
- About Us: description, experience, specialties
- FAQ: add/edit/delete and show/hide
- Privacy Policy: edit
- Section Visibility: turn public sections and animations on/off
- Security: password protection toggle (OFF by default), set/change password
- Export / Import settings JSON
- Public enquiries are stored locally and shown in Admin overview

## Important limitation

This is a GitHub Pages/static demo. Data and uploaded images are browser-local. For multi-device/real customer management, connect this same data model to Supabase/Firebase (or another backend), cloud media storage and authentication.
