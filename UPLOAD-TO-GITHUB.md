# Upload to GitHub Pages

1. Replace the current root files with this package: `index.html`, `data.js`, `script.js`, `style.css`, `admin.html`, `admin.js`, `admin.css`, `template.json`, `preview.svg`, `README.md`.
2. Commit to the branch used by GitHub Pages.
3. Open `/admin.html` to edit the site.
4. Open `/` to see the public website.

The admin uses browser `localStorage`. For real shared admin control, a backend and authentication are required.
