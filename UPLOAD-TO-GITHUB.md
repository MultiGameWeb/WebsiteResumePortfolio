# Upload steps

1. Keep these files together at the repository root:
   - index.html
   - data.js
   - script.js
   - style.css
   - admin.html
   - admin.js
   - admin.css
   - template.json
   - README.md
   - UPLOAD-TO-GITHUB.md
2. Upload the `assets/` folder as well.
3. Commit to the branch used by GitHub Pages.
4. Public website: `/index.html`
5. Admin panel: `/admin.html`
6. `preview.svg` is optional for the standalone website. Keep it only when a marketplace thumbnail is needed.
7. The admin image picker uses browser storage. No hero image URL or gallery image URL fields are required.
